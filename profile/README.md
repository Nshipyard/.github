# Open Nshipyard

An independent lab shipping open-source software with real impact on people's lives and businesses.

Open Nshipyard builds open infrastructure. The lab has shipped 33 products, 11 of them live, and its open-source work turns messy public data into infrastructure anyone can use: Canada's civic data as explorers, APIs, and MCP tools, natural-language search over satellite imagery, and live tropical cyclone risk alerts.

## What we ship

- 🍁 **Canada open data** — [canada.nshipyard.com](https://canada.nshipyard.com): Canada's civic data as explorers, charts, REST/OpenAPI, and MCP servers, starting with Toronto. Nine live projects: [Geo Concordances](https://github.com/Nshipyard/toronto-geo-concordances) (every neighbourhood boundary, joined across census years), [Licence → NAICS](https://github.com/Nshipyard/toronto-licence-naics) (160,000 business licences mapped to NAICS codes), [Watermain Codebook](https://github.com/Nshipyard/toronto-watermain-codebook) (the codes behind the pipes, finally documented), [Parcel Spine](https://github.com/Nshipyard/toronto-parcel-spine) (one stable ID for every Toronto property), [311 Taxonomy](https://github.com/Nshipyard/toronto-311-taxonomy) (850+ request types, versioned), [Parking Tickets, Geocoded](https://github.com/Nshipyard/toronto-parking-tickets-geocoded) (50 million tickets, mappable for the first time), [Civic Codebooks](https://github.com/Nshipyard/toronto-civic-codebooks) (NOC, infraction, and procurement codes in one reference), [Development Pipeline](https://github.com/Nshipyard/toronto-development-pipeline) (every housing-pipeline project, normalized and queryable), and [My Street](https://github.com/Nshipyard/my-street) (live road work and 202,779 building permits by street)
- 🛰️ **earthquery** — [github.com/Nshipyard/earthquery](https://github.com/Nshipyard/earthquery): ask the planet a question; natural-language vector search over satellite tiles
- 🌀 **cyclonewatch** — [github.com/Nshipyard/cyclonewatch](https://github.com/Nshipyard/cyclonewatch): live tropical cyclone risk alerts built on official hurricane forecasts
- 🚢 **The studio** — [nshipyard.com](https://www.nshipyard.com)
